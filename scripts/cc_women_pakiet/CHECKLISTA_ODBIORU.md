# CHECKLISTA ODBIORU — RADIO CC WOMEN

## Prawa / pliki / streaming
- [ ] Źródła utworów są oryginalne / legalnie udostępnione, z prawem do webcastingu
- [ ] Referencyjna playlista YouTube nie jest źródłem pozyskiwania audio
- [ ] Manifest i M3U zawierają tylko zaakceptowane, nieduplikowane utwory
- [ ] Hosting jest bez dodatkowej opłaty i spełnia wymogi 24/7
- [ ] Strumień jest publicznie dostępny przez HTTPS, z prawidłowym MIME
- [ ] Odtwarzanie z różnych urządzeń wskazuje ten sam sygnał radiowy

## UI i kompatybilność
- [ ] Nowa stacja jest widoczna w selektorze
- [ ] Logo CCW 1:1 i responsywny widok
- [ ] Play/Pause działa po interakcji użytkownika
- [ ] Zmiana stacji wyłącza poprzednią (brak nakładania się dźwięków)
- [ ] Zmiana głośności, wyciszenie, mobile/desktop
- [ ] Chrome / Firefox / Safari / Android / iOS
- [ ] Pozostałe stacje bez regresji

## Program muzyczny
- [ ] Shuffle całej rundy, brak powtórek przed wyczerpaniem listy
- [ ] Sprawdzono granicę rund; brak gwarancji bez osobnej implementacji
- [ ] Utwór niedostępny -> bezpieczne obsłużenie błędu
- [ ] Restart hosta -> powrót emisji, jeśli infrastruktura działa 24/7
- [ ] Kontrola poziomu głośności, brak przesterowania
- [ ] Dodanie utworu po zatwierdzeniu nie kończy aktualnego utworu

## Bezpieczeństwo i publikacja
- [ ] Hasła nie znajdują się w repozytorium, logach ani w przeglądarce
- [ ] Nie wdrożono ukrytego odtwarzacza YouTube
- [ ] Rollback i monitoring przygotowane
- [ ] Zebrano raport z testów, URL strumienia i zmienione pliki
- [ ] Po usunięciu materiałów testowych stacja nadaje wyłącznie zatwierdzone audio
