# @Skaner / @A008 — checklista

- [ ] Zweryfikowano właściciela oraz dostęp do każdego kanału.
- [ ] Sprawdzono czy kanał może tworzyć posty.
- [ ] 1080 × 1080 px, format wspierany przez YouTube, do 16 MB.
- [ ] Grafika i tekst zgodne z marką CC, czytelne na telefonie.
- [ ] Każdy post zawiera zwięzły opis, CTA i zweryfikowany URL.
- [ ] Język właściwy dla kanału; bez powtarzania identycznego spamu.
- [ ] Link zewnętrzny klikalny, jeśli kanał ma wymagane funkcje zaawansowane.
- [ ] Zgoda człowieka przed publikacją/harmonogramem.
- [ ] Po publikacji zapisany prawdziwy URL i data; brak fałszywych deklaracji.
- [ ] Raport w skrzynce agentów; brak sekretów i danych osobowych.
