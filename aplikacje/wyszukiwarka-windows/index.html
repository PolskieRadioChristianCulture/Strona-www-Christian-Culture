Jak zainstalować

  1. Kliknij Pobierz dla Windows i otwórz pobrany plik.
  2. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij Więcej informacji → Uruchom mimo to.
  3. Instalacja trwa kilka sekund. Ikona Christian Culture pojawi się na pulpicie i w menu Start.

Ostrzeżenie Windows pojawia się przy nowych programach bez płatnego certyfikatu wydawcy. Plik pochodzi tylko z polskieradio.cc. Suma kontrolna SHA-256: 707CF4E4B4385BDF69ADC0021C4380E51EE411BCF32492E23564A82B1979093A
